# Game Mouse — сайт

Лендинг программы **Game Mouse** — клавиатурная замена мыши для игр и работы
(для людей с ОВЗ, ДЦП, после инсульта). Управление курсором и кликами одной рукой
с цифрового блока клавиатуры (NumPad).

## Ссылки

- 🌐 Сайт (рус.): https://racerstarcity.github.io/game-mouse-site/
- 🌐 Site (English): https://racerstarcity.github.io/game-mouse-site/en.html
- ⬇️ Скачать установщик: https://github.com/racerstarcity/game-mouse-site/releases/latest/download/GameMouse_Setup.exe

## О программе

- Движение курсора по 8 направлениям, клики, перетаскивание, прокрутка — с NumPad.
- Работает в играх: виртуальная мышь на уровне драйвера (Interception, raw input).
- Снайперский режим (F7), профили под жанры (F6 — шутер/гонки/стратегия), оверлей.
- Windows 10/11, 64-бит. Для личного использования — бесплатно.

Драйвер Interception ставится из установщика (галочка) или из самой программы.

## English

**Game Mouse** is a free keyboard-to-mouse tool for one-handed gaming and work on
Windows 10/11. Move the cursor, click, drag and scroll using the numeric keypad.
Works in games via the Interception kernel driver (raw input). Made by an engineer
with cerebral palsy.
